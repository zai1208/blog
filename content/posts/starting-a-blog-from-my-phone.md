So, I'm still kinda new to this blogging thing, but we'll see how it goes.

So yesterday I woke up and decided that I want my own domain. But domains are expensive, and I did read somewhere that the GitHub student pack had some sort of free domain thing, so after some searching I manages to find the free domain for one year benefit and bought zain-khan.dev for free, for a year at least.
Now, configuring a website isn't without its challenges, especially since I couldn't be bothered to open my laptop. I ended up configuring everything from my phone.

Man, DNS takes forever to update, changing my domain on GitHub pages took forever because stupid DNS takes forever to update. In the meantime I ended up installing `dig` on the native terminal app on my phone in a debian environment. Eventually it worked and then I also ended up configuring my zoho mail account (<contact@zain-khan.dev>) and setting up this blog page. I again had another issue when I set up this blog page in that I forgot to add a theme with Hugo and so I had to clone the repo to my phone and then add it.

Well yeah, I guess that's this little adventure I had yesterday. Idk, I'm not good at this blogging thing.
